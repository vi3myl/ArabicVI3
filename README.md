# Security VI 🇸🇦

تعريب كامل لواجهة ديسكورد من مجتمع **Security VI**، مبني كمبادرة مجتمعية لتقديم تجربة عربية مريحة تراعي السياق اللغوي والثقافي. المشروع مفتوح للمساهمة، وأي شخص يقدر يقترح مصطلحات أو يحسّن الترجمة.

---

## 🆕 التحديثات الجديدة

- 🎨 **ثيم مخصص للبلوقين** بنفس الشكل الموضح في الصورة.
- 🌐 **تطوير التعريب**: أصبح أكثر استقراراً مع تحديث اللغة العربية.
- 🛠️ **إصلاح مشاكل**:
  - تعليق ديسكورد الشديد وارتفاع استهلاك المعالج (Freezing & High CPU).
  - الإغلاق المفاجئ للبلوقين واختفاؤه (Crash / Force Disable).
  - حماية نصوص الشات وحقول الكتابة.
